# 🏋️ Iron Gym

Landing page de uma academia fictícia, desenvolvida com HTML, CSS e JavaScript. O projeto tem como objetivo praticar o desenvolvimento front-end, com um visual moderno, responsividade e funcionalidades interativas.

## 🌐 Demonstração

Acesse o projeto online: [Iron Gym](https://lukanascimentosilva12.github.io/Iron-Gym/)

## 📌 Sobre o projeto

O Iron Gym é uma página web criada para representar o site de uma academia. O projeto apresenta informações sobre os benefícios dos treinos, planos de matrícula e formas de contato, utilizando uma identidade visual com tema escuro e detalhes em vermelho.

## ✨ Funcionalidades

- Navegação entre as seções da página.
- Apresentação dos benefícios da academia.
- Exibição dos planos Básico, Premium e VIP.
- Destaque visual para o plano mais popular.
- Layout responsivo para diferentes tamanhos de tela.
- Efeitos visuais e animações em CSS.
- Formulário de contato com validação dos campos.
- Botões para entrar em contato pelo WhatsApp.
- Mensagens personalizadas ao selecionar um plano.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, layout responsivo, animações e efeitos visuais.
- **JavaScript:** interatividade, manipulação do DOM e validação do formulário.

## 📱 Responsividade

A página foi desenvolvida para se adaptar a diferentes tamanhos de tela, incluindo computadores, tablets e celulares, proporcionando uma experiência de navegação mais adequada em cada dispositivo.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Estruturação de páginas com HTML semântico.
- Criação de layouts utilizando CSS.
- Aplicação de Flexbox e media queries.
- Desenvolvimento de interfaces responsivas.
- Criação de animações e efeitos visuais.
- Manipulação de elementos HTML com JavaScript.
- Validação de campos de formulário.
- Publicação de projetos utilizando GitHub Pages.

## ⚠️ Observações

Este é um projeto demonstrativo para fins de estudo e portfólio. O formulário de contato não possui integração com um servidor, e o número utilizado no WhatsApp é fictício, devendo ser substituído por um número válido para uso real.
